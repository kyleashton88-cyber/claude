# Example stills

These ten plates replace the code-drawn example frames. Each one is a real chart from the public index in `course/skills/real-market-charts/data/`, or an everyday analogy for the lesson's key idea.

They were generated on 6 November 2026 through the image path Stewart named for stills. The prompt carried the no-degradation clause: one Lanczos scale at render time, no second resample of the labels. Palette is Elite teal on navy. No exchange, brand, venue, or balance is on the plate. Dollar prices are not printed. Charts are stamped Example.

Creative Studio has not reviewed these files. Do not mark them pass. The lesson scripts still point `image` at the already-passed still, and the renderer swaps in this plate when `example.kind` is set.
