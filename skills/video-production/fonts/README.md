Inter and Roboto Condensed are bundled so a render does not depend on a macOS font pack.

| Family | Files | Licence |
|---|---|---|
| Inter | `inter/Inter-Regular.ttf`, `Inter-Medium.ttf`, `Inter-Bold.ttf` | SIL Open Font License, `inter/OFL.txt` |
| Roboto Condensed | `roboto-condensed/RobotoCondensed-Regular.ttf`, `RobotoCondensed-Bold.ttf`, plus the variable source | SIL Open Font License, `roboto-condensed/OFL.txt` |

`lib/fonts.py` checks these files before `/usr/share/fonts`.
