# Fonts

- `RobotoCondensed-Bold.ttf` is Roboto Condensed Bold, used for thumbnail and end-card headlines. License: `LICENSE-Roboto.txt` (Apache 2.0).
- `Inter-Bold.ttf` is Inter Bold, used for labels. License: `OFL-Inter.txt` (SIL Open Font License).

These files are the Pillow fallback. They are not fetched at runtime.
