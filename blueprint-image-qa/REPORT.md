## How it was scored

- Every ChatGPT image was viewed at full size and its labels checked word for word against its prompt or remake prompt. Margins were measured from the pixels: a text tag whose border sits under about 45px from a frame edge is a cramped-margin hard fail (the same bar that failed bp-01 004 v1).
- `check.py`'s cramped and off-brand flags were treated as advisory only.
- Code-drawn rows come from `qa-staging/code_drawn_e3d737e.json` (`blueprint-smoke/code-drawn/<path>.png` at e3d737e), merged by exact (lesson, path).

## Hashes: committed images vs uncommitted candidates

`scored_blob` is always the git blob id of the exact file that was scored. Look at `committed` before trusting it:

- `committed: true`: the scored file IS the file in the repo at that path. For lesson stills, analogies and the mascot that's this branch. For code-drawn rows it's `blueprint-smoke/code-drawn/<path>.png` on `cursor/blueprint-professional-rebuild-d1f6` @ e3d737e.
- `committed: false`: the scored file is a failed ChatGPT **candidate** in `out/` on the box that was NOT committed. The repo path still holds an older, uncleared blob. A candidate hash is never the image in the repo.
