## Hashes: committed images vs uncommitted candidates

`scored_blob` is always the git blob id of the exact file that was scored. What it points at depends on `committed`:

- `committed: true`: the scored file IS the file in the repo at that path. For lesson stills and analogies that's `cursor/blueprint-beginner-images` (this branch). For code-drawn rows it's `blueprint-smoke/code-drawn/<path>.png` on `cursor/blueprint-professional-rebuild-d1f6` @ 72e67cf. All 25 were checked with `git rev-parse 72e67cf:<file>`, and the 8 carried-over passes were checked to be equal to `d7125bc:<file>`.
- `committed: false`: the scored file is a failed ChatGPT **candidate** that was NOT committed (it lives in `out/` on the box). The repo path still holds an older blob that was never cleared. Never treat a candidate hash as the image in the repo.
